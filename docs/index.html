佐城雪美 · dsh-yukimi-theme

给 DeepSeek Harness Web 界面用的《偶像大师 灰姑娘女孩》佐城雪美主题
深蓝配色 · 卡面背景 · 磨砂侧栏 · 桌面宠物纸片小人

MIT License · 仅供个人学习与同好交流

主题色

#171C8F · 印象色
#2582C8 · 辅助
#4D6BFE · 辅助
#4fe3e1 · 暗色高亮

功能

  • 深蓝主题色（亮 / 暗自适应）
  • 角色卡面铺满背景，半透明透出
  • 淡蓝磨砂玻璃侧栏
  • 桌面宠物纸片小人：单击翻转 · 双击换衣 · 长按弹面板 · 可拖动 · 随机自动互动
  • Mobamas 卡片轮播（可拖动、点击切换）
  • 右下角签名铭牌
  • 助手文字描边 + 用户气泡半透明，提升可读性

卡面画廊

纸片小人（Petit）

安装

1. 把 @local/dsh-yukimi-theme 包放到 $DSH_HOME/profiles/node_modules/@local/ 下。

2. 编辑 $DSH_HOME/profiles/web/cordis.patch.yml：

- insert:
    - id: yukimi-theme
      name: '@local/dsh-yukimi-theme'

3. 重启：dsh web。

详见 GitHub README。
